# About This Project

This repository is a safe playground for learning Git. Nothing here is connected to production, so you can not break anything.

## Why Git matters

Git lets many engineers work on the same codebase without overwriting each other. Every change is recorded, reviewed, and can be undone.

## What you will do

You will create branches, resolve conflicts, and open pull requests. When your pull request is approved you will receive feedback from a mentor.

## Environments

Our real platform has a development, staging, and production environment. Code moves between them only after review.

## Getting help

If something goes wrong, do not panic. Ask your mentor. Most Git mistakes can be fixed, and you will have successfully learned something.
